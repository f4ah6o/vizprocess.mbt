# 2026-05-10

## process workspace session store

今日は `vizprocess` に durable process workspace session store を追加する。
実装前に `packages/vizprocess` の manifest / process 実装を確認し、既存の
`VizProcess` を source of truth として snapshot projection を作る方針にした。

実装計画:

- `packages/vizprocess/session_store.mbt` を追加し、`workspace`、`manifest`、
  `resolvedSources`、`nodes`、`attachments`、`selection`、`preview`、
  `diagnostics`、`lastAction` に対応する型を定義する。
- dataset / chart / artifact の flat summary projection を public function として
  追加する。
- manifest parse / validation 後に snapshot を更新する規則を
  `refresh_manifest` に閉じ込める。valid の場合は derived topology を差し替え、
  invalid の場合は attachments と preview は維持しつつ stale な nodes を消す。
- `docs/architecture.md` に OPFS は target architecture ではなく reference
  implementation だと明記する。
- `moon fmt`、`moon check`、`moon test`、必要なら `just test-js` で確認する。

`durable` は「ブラウザのタブを閉じても再開できる永続的な状態」という意味で使っている。
今回の session store は OPFS 固有の key-value state ではなく、App Server が保持して
複数 client から同じ process を再開できる contract として扱う。
