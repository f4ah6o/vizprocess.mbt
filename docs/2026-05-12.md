## Notes

OPFS は Origin Private File System の略で、ブラウザがその origin 専用に持つローカルファイル領域のこと。今回は CSV import と manifest 保存をここに置くことで、Cloudflare 側にユーザーデータを保存しない設計にした。

通常の validate/render は `packages/wasm` の JS target 出力を editor から import して実行する。Worker の `/api/editor/validate` と `/api/editor/render` は resolved manifest を受ける互換 API として残したので、API smoke と preview deployment の確認には使えるが、v1 の主経路ではない。
